# Changelog

## 1.2.1 - 2026-10-20

- Include the runnable JSON examples in installed wheels and source archives.

- Reject malformed or blank required text with actionable errors before rendering.
- Create report outputs exclusively, preserving existing files and dangling symlinks.
- Extend regression coverage and package the complete developer handoff documentation.

## 1.2.0 - 2026-10-16

- Added ordered named milestones and participant-order-independent selection of the earliest shared boundary.
- Rejected unordered, incompatible, duplicate and unknown labels, booleans and nonfinite numbers; preserved numeric comparison and single legacy through notes.
- Clarified that the public preset does not anonymize participant details.

## 1.1.0 - 2026-07-27

- Added typed chapter, issue, episode, season, quest, and timestamp boundaries.
- Added multi-person mutually safe boundaries, categorized exclusions, and sharing presets.
- Added duplicate-work validation and purpose-built Markdown output.

## 1.0.0 - 2026-07-26

- Released the first complete Spoiler Boundary Note Maker command-line workflow.
- Added deterministic reporting, representative examples, cross-platform tests, and explicit limitations.
